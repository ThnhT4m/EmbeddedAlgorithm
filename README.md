# 🔧 ALGO EMBEDDED

> Nơi tổng hợp và giải các bài toán giải thuật ứng dụng trong **Hệ thống Nhúng (Embedded Systems)**.

---

## 📌 Giới thiệu

Repository này được tạo ra nhằm:

* Luyện tập và nâng cao kỹ năng giải thuật
* Áp dụng tư duy thuật toán vào các bài toán thực tế trong hệ thống nhúng
---

## 🧠 Nội dung chính

Các bài toán trong repo tập trung vào:

* Cấu trúc dữ liệu cơ bản (Array, Linked List, Stack, Queue, ...)
* Giải thuật tối ưu (Sorting, Searching, Dynamic Programming)
* Bit manipulation (quan trọng trong embedded)
* Xử lý thời gian thực (Real-time constraints)
* Memory optimization (tối ưu bộ nhớ)
* Các bài toán mô phỏng phần cứng

---

## ⚙️ Công nghệ sử dụng

* Ngôn ngữ chính: `C / C++`
* Compiler: `GCC / ARM GCC`
